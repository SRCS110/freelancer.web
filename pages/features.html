Modules & Capabilities

Built for deep work, not corporate bloat.

Every module inside Rogue OS replaces scattered third-party apps with a unified dark-mode workspace.

01 / OVERVIEW

Dashboard

KPI cards (revenue, expenses, outstanding, active projects) with period filter. Overdue invoice alerts and quick action bar.

02 / CRM

Clients

Client card grid with full client file — contact info, linked projects, invoices, and document storage (contracts, NDAs, content forms, service agreements).

03 / MANAGEMENT

Projects

Project cards with status filter. Per-project file with description, budget, deadline, connection credentials, and an iPhone-style to-do list with priorities and due dates.

04 / ACCOUNTING

Finances

Income/expense log with period filter, project/client linking, tax estimates, and per-project income breakdown.

05 / BILLING

Invoices

Line-item invoices with PDF export (via jsPDF — no popup). Complete Draft → Sent → Paid / Void flow.

06 / STRATEGY

Business Plan

Mission, vision, market, revenue model, SWOT analysis, and goals tracker (90-day / 1-year / 5-year) with plain-text export.

07 / VAULT

Bookmarks

Website and tool manager with PIN-protected credential storage (email, username, password) and monthly cost tracking.

08 / SAAS BURN

Tech Stack

Recurring subscription tracker — calculates monthly burn rate and annual total, grouped by category.

09 / SYSTEMS

Workflows

Reusable SOP templates with ordered steps. Start a live "run" linked to a client or project and tick off steps with real-time notes.

10 / IDEATION

Brainstorm

Guided thinking sessions (New Service Idea, Client Pitch, Quarterly Goals, Problem Solving) or free-form notes with tag filtering.

11 / SYSTEM CONFIG

Account & Settings

Display name, business name, currency, tax rate, timezone, credential PIN setup, and password management.
